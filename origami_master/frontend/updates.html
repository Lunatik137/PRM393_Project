Updates to Origami Master App

3. Home Feed Screen (Updated from Home Screen)

3.1 Purpose

The Home Feed Screen serves as the primary social hub of Origami Master. It displays origami creations published by followed users and recommended creators. Users can discover new creations, interact with posts, follow creators, and engage with the community through a continuously scrolling social feed.

3.2 UI Component

SectionComponentData TypeDescription
HeaderApp LogoImageDisplays Origami Master branding.
HeaderSearch ButtonIcon ButtonOpens content search.
BodyFeed ListInfinite ListDisplays social feed posts.
BodyFeed Post CardCardDisplays creation image, creator, and interaction statistics.
BodyCreator AvatarImageDisplays post creator profile image.
BodyCreator UsernameLabelDisplays creator username.
BodyCreation ImageImageDisplays published origami creation.
BodyFold Model NameLabelDisplays associated origami model.
BodyLike CountLabelDisplays total likes.
BodyComment CountLabelDisplays total comments.
ActionLike ButtonButtonLikes or unlikes a post.
ActionComment ButtonButtonOpens comments for the selected post.
ActionFollow ButtonButtonFollows or unfollows the creator.
BottomBottom Navigation BarNavigationProvides access to Home, Explore, Gallery, and Profile.

3.3 User Flow

  1. User opens Home Feed Screen.
  2. System loads posts from followed users.
  3. System loads recommended posts.
  4. User scrolls through the feed.
  5. User may like, comment, or follow creators.
  6. User may open a post or creator profile.

8. Completion Result Screen (UPDATE)

Thêm UI Component

SectionComponentData TypeDescription
ActionPublish To Feed ToggleToggleDetermines whether the completed creation will be published to the social feed.

User Flow (Bổ sung)

  • The user completes an origami lesson.
  • The system saves completion information.
  • The user chooses whether to publish the creation to the social feed.
  • If Publish To Feed is enabled, the system creates a feed post.
  • The user may generate a share link.
  • The user may return to Home Feed or Gallery.
